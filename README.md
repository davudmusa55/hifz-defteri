# Hıfz Defteri

Osmanlı usulüyle Kur'an-ı Kerim ezber planı. Çevrimdışı çalışan bir web uygulaması (PWA).

**Uygulama:** https://davudmusa55.github.io/hifz-defteri/

iPhone'da Safari'de açıp **Paylaş → Ana Ekrana Ekle**, Android'de Chrome'da **Uygulamayı yükle** ile kurulur.

## Veriler

Ezberler, ilerleme ve program **yalnızca kullanıcının kendi cihazında** (IndexedDB) saklanır; hiçbir sunucuya gönderilmez. Bu depoda kullanıcı verisi yoktur. Cihazlar arasında taşımak için uygulamadaki *Ayarlar → Verilerimi dışa aktar / içe aktar* kullanılır.
